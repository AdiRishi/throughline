# The `gh` CLI Is Reached Through One Injectable Runner

Throughline reads GitHub only through the reviewer's `gh` login — no app token, no OAuth flow of our own, and nothing persisted. Even `cloneToken` just runs `gh auth token` and hands the result to `git`. Every invocation passes through a single seam, `apps/server/src/github/GhRunner.ts`, which exposes exactly two things: `run(args, options)`, whose failures arrive already typed, and `classify(exitCode, stderr, stdout)`, which decides what a non-zero exit _means_.

Calling `runProcess("gh", …)` from `process/run.ts` at each call site is the obvious path, and was rejected because `gh` reports nearly everything as exit 1 with prose on stderr, so "what went wrong" is signature matching over that prose: an exhausted quota, a login that has expired, a secondary limit, a 404 indistinguishable from a private pull request. Spread across call sites that knowledge drifts, and can only be exercised against a real `gh` and a real network. Behind the seam `GhRunner` is a `Context.Service`, so `GitHub.layerRequiringRunner` can be handed a scripted runner that records every call — which is what makes `apps/server/tests/github/GitHub.test.ts` possible: it drives the adversarial cases under `TestClock` and asserts on **request counts**, twenty concurrent PR-list readers producing exactly one GraphQL call and a parked module producing zero — not even for a user-initiated `refreshPrs`.

One ordering detail inside `classify` is load-bearing: the secondary-rate-limit branch must be checked _before_ the primary one, because a secondary-limit message also contains the words "rate limit". Reversed, it would be read as an exhausted quota and parked against `x-ratelimit-reset` instead of the `retry-after` it actually carries.

The structural rate discipline sits above the seam, in `GitHub.ts`: a width-2 semaphore that every request goes through, per-kind `Cache` TTLs (an hour for identity, sixty seconds for the list, thirty for a PR's detail; failures never cached), and a `parkedUntil` gate that only ever extends. `toGitHubError` takes `nowMillis` as an argument rather than reading the clock, so classification stays a pure function of time passed in. A direct spawn added anywhere else would silently bypass the gate and the park, and take the counting tests with it.
