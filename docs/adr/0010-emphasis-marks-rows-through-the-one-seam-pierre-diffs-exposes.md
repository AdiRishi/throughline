# Emphasis Marks Rows Through The One Seam @pierre/diffs Exposes

A cluster's boundary is carried by emphasis and dimming across the whole file, never by rendering only the cluster's hunks. Every file stays present and complete; hunks homed to the open cluster take the product's single accent, hunks homed elsewhere are dimmed and labelled with their home. Concretely that means writing `data-tl-focus` / `data-tl-revisit` / `data-tl-dim` onto rendered rows and letting one stylesheet style them — `apps/web/src/journey/emphasis.ts`, wired through `apps/web/src/journey/CodeSurface.tsx`.

Filtering the rendered diff down to the cluster's hunks would be less code and less DOM. Exclusion was rejected because it hides the partition: a reviewer who only sees this cluster's hunks cannot tell that the rest of the file belongs somewhere else on the journey.

The mechanism is not a preference. Each file `@pierre/diffs` renders lives in its own open shadow root — `<diffs-container>` calls `attachShadow({ mode: "open" })` — so no global stylesheet and no `className` can reach a code row. Exactly two hooks can: `onPostRender`, which hands over the host element and therefore its shadow root, and `unsafeCSS`, injected into that shadow root inside the library's `unsafe` cascade layer. The library rewrites that `<style>` node whenever the string differs, which is why `EMPHASIS_CSS` and `JUST_THE_CODE_CSS` are module constants, not per-render templates.

One correctness constraint a naive implementation gets wrong: `data-line` is the row's _own-side_ number, filled from `additionLine.lineNumber` on a `change-addition` row and `deletionLine.lineNumber` on a `change-deletion` row, with `data-alt-line` left undefined for changed lines. A numeric range match that does not branch on `data-line-type` first highlights the wrong code — new line 12 and old line 12 are different lines.

Two more, each already paid for in debugging. `CodeView` pools its container hosts and re-renders partially as rows scroll in, so both branches of every marker must be written on every pass (`toggleAttribute(name, condition)`, never a bare set) or a stale mark leaks onto the next file the recycled host renders. And the stylesheet must never hide `[data-diffs-header]`: with a custom header that element contains only a `<slot>`, and `renderCustomHeader` portals the per-file header into it — hiding it takes Mark read, the product's primary interaction, off the screen.
