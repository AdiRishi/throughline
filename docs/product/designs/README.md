# Screen Designs

Throughline's own screens — iterated and near-final. Distinct from [`../external-references/`](../external-references/README.md), which holds _other products'_ screenshots.

These images are the visual source of truth for **layout, hierarchy, and tone**. The written documents remain the source of truth for **behavior**: every state, rule, and guarantee. Where a design and a document disagree, the documents win until they are amended — treat a disagreement as a bug to raise, never a choice to make silently.
